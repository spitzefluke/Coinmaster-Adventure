Checkliste

Was ist schon überarbeitet, was muss noch überarbeitet werden, und wer macht was. Beide Admins sehen dieselbe Liste und melden sich mit ihrem eigenen Code an, den jeder beim ersten Mal selbst festlegt.

Gespeichert in Supabase. Ansehen und bearbeiten nur mit Code; die Tabellen und Funktionen stehen in checkliste/supabase.sql.

Anmelden

Jeder Admin hat seinen eigenen Code. Am Code erkennt die Liste, wer du bist. Er bleibt in diesem Browser gespeichert, bis du dich abmeldest, darum nur auf eigenen Geräten anmelden.

Zum ersten Mal hier?

Dann leg jetzt deinen eigenen Code fest (mindestens 8 Zeichen, z. B. drei Wörter und eine Zahl). Das geht je Name nur einmal; danach meldest du dich damit an.
