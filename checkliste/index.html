Checkliste

Was ist schon überarbeitet, was muss noch überarbeitet werden, und wer macht was. Beide Admins sehen dieselbe Liste; jede Änderung landet als Commit im Repo.

Gespeichert in checkliste/daten.json im Repo. Die Liste ist wie die ganze Webseite öffentlich lesbar; bearbeiten kann nur, wer einen GitHub-Token mit Schreibrecht hinterlegt.

Anmelden

Zum Abhaken braucht die Seite einen GitHub-Token mit Schreibrecht am Repo. Er bleibt nur in diesem Browser gespeichert, darum nur auf eigenen Geräten anmelden.

Wer bist du?
So bekommst du einen Token
  1. Besitzer des Repos (spitzefluke): fein abgestuften Token anlegen. Unter „Repository access“ nur Coinmaster-Adventure wählen, unter „Permissions“ bei Contents „Read and write“. Ein Ablaufdatum setzen.
  2. Zweiter Admin (Axseleins): Zuerst lädt der Besitzer dich ein (Repo → Settings → Collaborators → Add people), du nimmst die Einladung an. Dann einen klassischen Token mit Häkchen bei public_repo anlegen (bei einem privaten Repo repo). Fein abgestufte Tokens dürfen nicht in Repos anderer Personen schreiben.
  3. Den Token hier einfügen und „Anmelden“ drücken. Abmelden löscht ihn wieder aus diesem Browser.
